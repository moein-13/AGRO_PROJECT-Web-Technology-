# AGRO — Farmer Support & Crop Market Portal

A web-based platform built for **Web Technologies** using an MVC-inspired structure with **PHP, MySQL (XAMPP), HTML, CSS, and JavaScript**. AGRO is designed to support farmers and streamline crop market interactions through dynamic web pages and server-side database operations.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (AJAX / DOM manipulation)
- **Backend:** PHP
- **Database:** MySQL (via XAMPP)
- **Architecture:** MVC-style folder layout (`models/`, `views/`, `controllers/`)

---

## Project Structure

```text
Agro_Project/
├── controllers/     # Request handling & business logic
├── css/             # Stylesheets and UI styling
├── images/          # Static image assets
├── js/              # Client-side scripts & AJAX interactions
├── models/          # Database queries & data layer
├── views/           # User interface templates & pages
